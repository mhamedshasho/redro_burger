# Redro Burger Engine

A custom lightweight 2D game engine and burger-restaurant game for Android.

## Principles
- No Godot, Unity, or other ready-made game engine.
- Engine systems are developed in this repository.
- SDL3 is used only as a platform/input/audio library; it is not the game engine.
- C++ and CMake for the native core.
- Android builds will be added after the desktop engine core is validated.

## Planned systems
- Core application loop
- Renderer and texture resources
- Input abstraction
- Scene and entity management
- 2D collision
- Audio
- UI widgets
- Restaurant gameplay: recipes, customers, orders, money, upgrades, and save data

## Current status
Early project scaffold. No APK is available yet.
